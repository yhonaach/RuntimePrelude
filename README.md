# RuntimePrelude

Monitors system performance metrics and resource usage in real-time for developers and system administrators.

With RuntimePrelude, you get a lightweight tool that stays out of your way.

**What you get**

- Monitors system performance metrics and
- resource usage in real-time for
- developers and system administrators

## Key Features

- Monitors system performance metrics and
- resource usage in real-time for
- developers and system administrators

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/RuntimePrelude.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

RuntimePrelude is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
